# ContaFácil

Sistema web de gestão e organização de atividades contábeis.

## Sobre o projeto

O ContaFácil é um sistema desenvolvido como projeto final
da disciplina de Programação Web II, do Colégio Técnico
de Teresina (UFPI).

A proposta é facilitar a comunicação e a organização
entre escritórios de contabilidade e seus clientes,
centralizando informações, documentos e obrigações
contábeis em um único ambiente.

## Objetivos

- Organizar o cadastro de clientes.
- Gerenciar obrigações e prazos contábeis.
- Centralizar documentos enviados pelos clientes.
- Facilitar o acompanhamento de pendências.
- Apresentar indicadores em um painel de controle.

## Tecnologias

- PHP 8+
- MySQL
- PDO
- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Funcionalidade diferencial

**Radar Contábil:** recurso planejado para identificar
prazos próximos, obrigações atrasadas e documentos pendentes.
